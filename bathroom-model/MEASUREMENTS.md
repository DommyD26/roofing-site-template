bathroom, so grout lines are a built-in tape measure. All five photos were
EXIF-uprighted, contrast-enhanced, and measured by counting grout lines along
each fixture's base line (toe kicks, baseboards, door sills, curb, tub apron).
Nine independent counting passes were run (separate analysts per run), plus
perspective-model fits (1/(y−h) row progression, vanishing-point column
tracing, metric rectification of IMG_9298 from 3 vanishing points).
